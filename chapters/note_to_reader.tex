\section*{Document Conventions}
Links are shown in:
\begin{itemize}
    \item \textcolor{blue}{blue} for internal links to other parts within this book, such as chapters, sections, glossary, and page numbers.
    \item \textcolor{red}{red} for citation links to the reference section.
    \item \textcolor{orange}{orange} for external links outside the book, such as a website, \href{https://www.youtube.com/@gillespilon13}{YouTube channel}, etc.
\end{itemize}

\section*{Software user interface}
\begin{itemize}
    \item \textcolor{SelectItem}{Caribbean mint} for selecting an item in a list.
    \item \textcolor{UserInput}{neon pink} for text to enter.
\end{itemize}

Code and shell commands are shown in:
\begin{itemize}
    \item Shell commands (zsh, bash) are shown inside a box outlined in black, with a note above it that identifies it as shell commands.
    \item Python commands are shown inside a box outlined in black, with a note above it that identifies it as code.
\end{itemize}
